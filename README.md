# Progetto Front-End per Generation

Applicazione SPA con integrazione di database MySQL e operazioni CRUD.

**Stack**: Express, React, Node.js, MySQL

## Guida Installazione

1) Scaricare il progetto .zip
2) Estrarlo ed aprirlo in Visual Studio Code
3) Aprire un doppio terminale:
   - Terminale 1: `cd bank-frontend && npm i`
   - Terminale 2: `cd bank-backend && npm i`
4) Nel terminale frontend avviare: `npm run dev`
5) Nel terminale backend avviare: `node server.js`

Così sia server che client verranno avviati e potranno scambiarsi chiamate HTTP.

## Funzionalità

- Gestione clienti (CRUD)
- Gestione conti correnti
- Gestione transazioni tra conti
- API REST con prepared statements

## Accesso

Frontend: http://localhost:5173
Backend: http://localhost:8080
